## 条件役专题详解

- 雀魂振听按舍牌判定：暗杠、加杠、拔北的牌不纳入舍张振听，放过这些操作的和牌响应也不会新增振听；已有振听仍限制抢杠、抢北。完成的杠或拔北仍中断一发。
- "两立"与普通"枪杠"不能复合：双立直前不能有碰；之后放过形成该碰的原始待牌舍牌，会进入永久振听，舍牌被碰走不撤销见逃。受限的是原始舍牌，不是后来的加杠响应。普通立直前已有碰6m、随后非振听立直听3m和6m时，放过6m加杠仍可荣和后来打出的3m。
- "枪杠"无法与"七对", "对对", "混老", "二杯"复合, 若能与"三暗"复合一定是门清状态
- "岭上"与"平和", "七对", "二杯"能复合只有三麻的拔北能做到
- "自摸"与"对对"无法复合
- "两立", "一发"无法同时与"三杠"复合
